## ⚙️ Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/Ganeshkaithoju/Kaithoju-Ganesh-Portfolio.git
cd Kaithoju-Ganesh-Portfolio
```

### 2. Install dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 3. Configure environment variables

Create a local environment file based on the provided example:

```bash
.env.example
```

Create:

```text
.env
```

and provide the required values.

> **Never commit `.env` or any file containing real credentials, API keys, tokens, passwords, or private configuration.**

### 4. Start the development server

```bash
npm run dev
```

The application will start using the development configuration defined by the project.

### 5. Build for production

```bash
npm run build
```

## 🔐 Security

Sensitive configuration is intentionally excluded from this repository.

The following should **never** be committed:

* `.env`
* API keys
* Service-role keys
* Database credentials
* Passwords
* Authentication secrets
* Private tokens

Use `.env.example` as the reference for required environment variables.
